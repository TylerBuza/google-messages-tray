# v1.0.4 — Bring Messages to the foreground from the tray

Fixes tray double-clicks sometimes restoring Messages underneath other windows, particularly while notification previews are pending.

## Fixed

- Explicit open actions select the Messages page and activate its native Chrome window.
- Handle Windows foreground restrictions between the separate tray, helper, and Chrome processes, releasing temporary input-queue attachments immediately after activation.
- Exclude Chrome tooltips and tool windows from native restore/focus handling, and activate one real app window rather than each Chrome-owned window in turn.
- Dismiss pending popup previews when explicitly opening Messages. This does not mark conversations read automatically or remove their messages.
- Preserve maximized state when showing a hidden window; restore normally when minimized.
- Keep foreground activation limited to explicit open requests. Incoming notifications still do not steal focus, and Messages is not left permanently always-on-top.
- Load the bundled native helper as an unpacked script file instead of an encoded command that can exceed Windows' command-line limit.

## Download / upgrade

Download **Messages-Tray-1.0.4.exe**. Quit the old app from its tray menu before starting the update. Sign-in and phone pairing remain in the same dedicated profile. If you use Start with Windows, disable it in the old version and enable it in the new one after placing the EXE in its final folder.

Releases remain unsigned. Checksums verify file integrity, not publisher authenticity or safety. Review any VirusTotal results in the release notes rather than treating a successful upload as a clean verdict.

## Validation

All 38 unit tests passed. The app smoke test verifies foreground activation with a pending notification and a competing window, checks that Chrome is not left topmost, and restores Messages after a 300-message notification burst. Existing popup sizing, unread-badge, external-link, and X-to-tray checks remain included.

Windows can still restrict activation on secure desktops or while a target application is unresponsive. This is an unofficial public beta, not affiliated with Google. Existing notification and privacy limitations still apply.
