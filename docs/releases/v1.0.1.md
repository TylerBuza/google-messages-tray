# v1.0.1 — Unread tray badge

A small red dot now appears on the Messages Tray icon when Google Messages has observed unread conversations.

## What's new

- Red-dot unread indicator in the tray icon's top-right corner.
- The badge updates from Google's conversation unread flags, including messages already unread when the app starts.
- Reading those conversations clears the badge; merely showing the window does not.
- The badge keeps working while notification popups are paused.
- Known unread rows are remembered when Google's virtual conversation list scrolls them offscreen.
- The tray tooltip indicates unread messages without displaying message contents.

## Download / upgrade

Download **Messages-Tray-1.0.1.exe** and quit the previous version using its tray menu before launching it. Your existing dedicated Chrome sign-in and pairing are preserved. If you use Start with Windows, disable it in the old version and enable it in the new one after placing the EXE in its final folder.

**SHA256SUMS.txt** contains the download checksum. Releases remain unsigned; a checksum checks file integrity, not publisher authenticity or safety.

## Scope and validation

The badge reflects unread flags observed in Google's conversation list, not a guaranteed account-wide count. Older unseen chats or read/deletion changes outside the rendered list can require reopening the relevant list area or reloading Messages. The app does not open conversations or mark texts read automatically.

All 15 unit tests passed. The packaged EXE passed the synthetic notification, unread-to-read badge, X-to-tray, and restore smoke test. Live local feedback also confirmed the badge works; Google compatibility can still vary.

Windows 10/11 x64, installed Chrome, and Google Messages phone pairing are required.
