# v1.0.3 — Compact popups and notification burst fix

Fixes a freeze when several notifications arrive together and removes unused space below notification cards.

## Fixed

- Removed a loop that waited for an asynchronous Electron window close while blocking the event loop needed to finish that close.
- Reuse a maximum of three active popup windows during bursts, rather than repeatedly creating and closing windows.
- Coalesce rapid messages from the same chat into the latest preview, with renderer deliveries batched to at most one per 50 ms per popup.
- Keep hovered previews stable; pending updates are applied when the pointer leaves.
- Size popup windows to their content and stack them using their individual heights.
- Apply stable geometry at fractional Windows display scaling to avoid repeated-rounding growth.
- Validate code-copy actions against the displayed notification revision, so a delayed response cannot overwrite a newer code button.
- Retire popup slots synchronously before requesting a native window close, including pause, lock-screen, dismiss, and renderer-failure cleanup.

## Download / upgrade

Download **Messages-Tray-1.0.3.exe** and quit the previous version using its tray menu before launching the update. If the old version is frozen, end its Messages Tray process in Task Manager, then launch the update. Your dedicated Chrome sign-in and pairing profile is preserved. If the dedicated Chrome process remains open after force-stopping an old tray process, close its window before relaunching; do not terminate your regular Chrome session.

If you enabled Start with Windows, disable it in the old version and enable it in the new one from its final folder. The release remains unsigned. The published checksum checks integrity, not publisher authenticity or safety.

## Validation

All 28 unit tests passed, including a 10,000-message popup-policy stress test and asynchronous-close regression coverage. The app smoke test includes 300 synthetic notifications through real Electron popup windows, verifies bounded window use and content-sized geometry, and checks existing unread-badge, link-routing, notification, and X-to-tray behavior.

Burst previews intentionally show the latest messages rather than an unlimited popup backlog. Messages remain available in Google's conversation view; the companion never marks them read automatically. Existing best-effort notification and privacy limitations still apply. This is an unofficial public beta, not affiliated with Google.
