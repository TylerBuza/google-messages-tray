# v1.0.6 — Phone low-battery tray indicator

Adds an amber battery marker at the tray icon's bottom-left, opposite the red unread dot at top-right. Both indicators can appear together.

<img src="https://raw.githubusercontent.com/TylerBuza/google-messages-tray/v1.0.6/docs/images/tray-indicators.png" width="640" alt="Tray preview showing the red unread dot, amber phone-battery marker in the opposite corner, and both indicators together" />

*Actual tray compositor, enlarged for visibility. Amber follows Google's warning; it is not a measured battery percentage.*

## Included

- Observe Google's own **Phone battery low** device-warning banner, not SMS bodies or conversation snippets.
- Update the amber marker independently of unread status, including while notification popups are paused.
- Add phone-battery warning status to the tray tooltip.
- Clear the marker when the warning is hidden/removed/dismissed or the Messages page becomes unavailable.
- Render all four tray states locally with the same bitmap compositor; no font/icon service is needed.

The indicator reflects Google's warning, not direct Android telemetry, a battery percentage, or the PC's battery. Dismissing a warning clears the marker even if the phone is still low. Detection currently recognizes the English Google Messages banner and can be affected by site/language changes.

## Download / upgrade

Download **Messages-Tray-1.0.6.exe**, save any draft, and quit the old app from its tray menu before launching the update. Existing sign-in and phone pairing remain in the same dedicated profile. Re-enable Start with Windows from the new EXE's final location if previously enabled.

The release remains unsigned. Verify its checksum and inspect live VirusTotal results rather than treating a successful submission as a clean verdict.

## Validation

All 51 unit tests passed. Tests cover the real device-banner shape, warning removal/dismissal, hidden banners, charging/non-battery status, SMS false positives, and independent bitmap overlays. The packaged smoke test checks battery/unread transitions independently, together with existing foreground-restore, compact-popup, 300-message-burst, link-routing, and X-to-tray behavior. The detector was also checked read-only against the live Google Messages device banner.
