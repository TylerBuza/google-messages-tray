# v1.0.5 — Clear stale unread tray badges

Fixes a red tray badge remaining set when Google Messages' loaded conversation list has no unread conversations.

## Fixed

- Recalculate unread status from the current conversation-list snapshot on every scan.
- Stop retaining historical unread flags for conversations that disappeared during read/archive/delete/sync/list updates.
- Clear the badge when the loaded list is empty or contains only read conversations.
- If an unread row becomes loaded again, reflect its current unread flag without replaying its old text as a new notification.

No conversations are opened or marked read to clear the badge. The badge remains a view of Google's currently loaded list, not a guaranteed account-wide unread count; unloaded conversations are reflected when Google loads them.

This build also includes the tray foreground-restore improvements from the recent local update: explicit open actions dismiss popup previews, select Messages, and activate its real Chrome window without leaving it permanently always-on-top. Chrome tooltips are excluded from focus handling.

## Download / upgrade

Download **Messages-Tray-1.0.5.exe**. Save any draft and quit the previous app using its tray menu before launching the update. Your dedicated Chrome sign-in and phone pairing profile are preserved. Re-enable Start with Windows from the new EXE's final location if previously enabled.
