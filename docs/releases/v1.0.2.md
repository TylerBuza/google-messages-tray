# v1.0.2 — Open message links in your normal browser

Web links from messages now open through Windows' default browser instead of the dedicated Messages Chrome profile. If Chrome is your default, links use your normal Chrome instance and its usual profile selection.

## Fixed

- Route normal, Ctrl-click, and middle-click message links outside the companion profile.
- Route external `window.open` links, new tabs/windows, and same-tab web navigation to the default-browser handler.
- Keep Google Messages and Google account sign-in navigation inside the app.
- Validate external URLs as HTTP(S), reject credentials/executable schemes, and suppress duplicate routing events.

The companion does not select among multiple normal Chrome profiles; Windows and Chrome control that behavior. Existing unread-badge, code-copy, and X-to-tray features remain available.

## Download / upgrade

Download **Messages-Tray-1.0.2.exe**. Quit the old version using its tray menu before launching the update. Your dedicated Chrome sign-in and pairing stay in the same profile. If you enabled Start with Windows, disable it in the old version and enable it in the new version after putting the EXE in its final folder.

**SHA256SUMS.txt** contains the download checksum. The EXE remains unsigned; a checksum verifies file integrity, not publisher authenticity or safety.

## Validation and limitations

All 21 unit tests passed. The packaged EXE passed the synthetic external-link routing, notification, unread-badge, and X-to-tray smoke test. Link tests use fictional URLs and a recorded default-browser callback; they do not open the user's normal browser during automated tests.

Windows 10/11 x64, installed Chrome, and a paired Google Messages phone are required. Notification detection remains best-effort and depends on Google's page implementation. Read the [README](https://github.com/TylerBuza/google-messages-tray#readme) and [Privacy](https://github.com/TylerBuza/google-messages-tray/blob/main/PRIVACY.md) for the existing local-debugging and notification limitations.
