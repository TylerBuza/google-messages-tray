# Google Messages Tray for Windows — public beta

Your texts in the tray. Your verification codes, one click away.

An unofficial, open-source Google Messages desktop companion for Windows. Keep Messages out of your regular Chrome tab bar, receive desktop text popups, and copy detected numeric verification codes with one click.

## Download

- **`Messages-Tray-1.0.0.exe`** — portable Windows x64 app; no installer or administrator rights required.
- **`SHA256SUMS.txt`** — SHA-256 download checksum. This verifies integrity, not publisher identity or safety.
- Source is available under the MIT license.

Requires Windows 10/11 x64, installed Google Chrome, and an Android phone using Google Messages. The EXE is **unsigned** and Windows may warn about it. Do not run an untrusted binary; inspect/build the source if preferred.

## Included

- Separate installed-Chrome app window with a dedicated profile.
- System-tray access, complete window hiding, and mouse X-to-tray behavior.
- Desktop popups with explicit Copy buttons for detected 4–8 digit codes.
- Pause, a synthetic popup test, last-code shortcut, and optional Windows startup.
- No app analytics, subscription, or message-forwarding server.

## Start

Run the EXE, sign in and finish pairing, then click X / Hide to tray. Double-click the tray icon to open Messages. Right-click → Quit Messages Tray to exit. If upgrading from a development build, quit the old companion first; its dedicated Chrome profile is kept.

## Important beta limits

Notification detection depends on Google's page implementation and is not guaranteed. These are custom popups, not Windows Notification Center toasts, and Windows Do Not Disturb does not control them. Numeric-code detection is heuristic. Alt+F4/system-menu Close are not intercepted. Google sign-in and incoming SMS require live user testing.

The companion uses a local Chrome debugging port accessible to other local software and a process-scoped mouse helper for X-to-tray. Read [Privacy](https://github.com/TylerBuza/google-messages-tray/blob/main/PRIVACY.md) before use on a shared PC.

Local validation: 8 unit tests passed; the portable EXE passed a synthetic notification-to-popup and native X-callback hide/restore smoke test. Synthetic tests do not guarantee real-world Google compatibility.
